# Melo visual system

The supplied task-management reference defines the visual language across patient, therapist and admin workflows. Preserve clinical content and existing actions while applying these shared patterns.

## Surfaces and color

Use a soft peach/lilac wash fading into a neutral grey page, white cards and inputs, charcoal text, and lime progress/selected accents. AppColors owns all colors and gradients. Cards use 28 px corners with a subtle shadow; compact surfaces use 16 px, and buttons/filters/navigation use capsules. Error red remains reserved for validation and destructive states. Sensor charts retain their dedicated high-contrast trace palette for readability.

## Typography

Bundle Nunito Sans locally at 400, 500, 600 and 700 weights. AppTypography owns the scale: hero 40, page heading 36, section heading 24, card title 20, body 16, label 14, caption 12. Use regular or medium headings, tight heading tracking, and sentence case. Hindi and Punjabi retain their bundled script fallbacks. Technical diagnostics may use JetBrains Mono.

## Components

- White borderless cards, generous whitespace and circular feature icons.
- Charcoal capsule primary actions, white secondary actions, visible focus and validation borders.
- Filled white rounded input fields with labels above, shared by every form.
- Dark selected filter capsules with white labels; white unselected filters.
- Compact white floating bottom navigation capsule with icons only; the active destination has a lighter charcoal circle. Destination names remain available through tooltips and accessibility labels.
- A charcoal home summary with a lime circular completion indicator and lime action.
- Consistent rounded sheets, dialogs, menus, date/time pickers and status chips.

## Layout and accessibility

Use the shared 4/8/16/24/32 spacing scale and 24 px page gutter. Preserve scrollability, safe-area insets, validation, empty/loading/error states, keyboard access and semantic labels. Actions have at least 48 px height. At narrow widths or enlarged text, summary content stacks instead of truncating. Keep functional values accurate; decorative examples from the reference are not application data.

## Motion

Use restrained 200–300 ms transitions and the existing reduced-motion-aware entry sequence. Avoid decorative textures, ink illustrations, serif headings and uppercase section labels from the previous design.
